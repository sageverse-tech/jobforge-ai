# ⚡ JobForge AI — Real-Time Job Search & Auto-Apply Tool

An open-source, AI-powered tool that helps job seekers automate their search and instantly generate highly personalized cover letters based on their resumes. Powered by Google Gemini 2.5.

## 🌟 Features
- 📄 **Bring Your Own Resume:** Upload your PDF resume directly into the app framework.
- 🔍 **Smart Job Search:** Search for any role (e.g., Software Engineer, ML Intern) across multiple platforms using Google Search Grounding.
- 🤖 **Gemini-Powered Cover Letters:** Matches resume skills with live job context to generate perfect applications.
- 📧 **Ready-to-Send Drafts:** Generates clean email structures ready for outbound submission.
